# Random Color Generator

A responsive random color generator built with HTML, CSS and JavaScript.

## Features

- Generate random colors instantly
- Display HEX color codes
- Change the background color dynamically
- One-click color generation
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

https://bashrat365.github.io/random-color-generator/

## Project Structure

random-color-generator/
├── index.html
├── style.css
└── script.js

## How It Works

When the user clicks the Generate Color button,
JavaScript creates a random HEX color code.

The generated color is then applied to the color box,
and the HEX code is displayed on the screen.
